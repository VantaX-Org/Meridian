# v0.0.660

Previous release with notes: v0.0.659.

## Summary

This release adds the design system and component kit for the app-like Meridian redesign. It is opt-in and changes nothing for existing users: the new screens sit under /next and are reached only when a person turns on "Try the new Meridian" in Preferences.

## Features

- Design tokens for light and dark, with accent #1F5EFF in light and #6B96FF in dark, and a motion scale of 120, 200 and 320 ms that honours reduced motion.
- Inter and JetBrains Mono, self-hosted.
- Inline SVG icon set.
- Eighteen kit components: Button, Chip, StatCard, Stepper, RunSwitcher, DataTable, SidePanel, Toast, Confirm, EmptyState, ErrorState, Skeleton, CommandPalette, Tabs, SegmentedControl, Code, DropZone and ProgressBar. All are keyboard operable, show visible focus and work at phone width.
- A kit page at /next/kit showing every state in light and dark side by side.
- Per-user preference `ui.next` ("Try the new Meridian", default off), read through one hook.
- English, German and Japanese copy for all new text.

## Checks

- Raw colour values are banned under design/next outside tokens.css, by the token lint and by a unit test.
