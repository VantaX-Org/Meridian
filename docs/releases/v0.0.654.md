# v0.0.654

Previous release with notes: v0.0.653.

## Summary

Administration has an SAP systems section. It lists every connected system with its host, client, instance, environment and connection health, and links to each system's connection settings and to the screen that connects a new system.

## Features

- Administration, SAP systems: one row per system, with a link that opens its connection settings, and a "Connect a system" action. The section needs the manage systems permission.
