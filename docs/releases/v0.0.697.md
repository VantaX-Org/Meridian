# v0.0.697

Status: not yet tagged. This note covers the next-kit port of People, the System page, the admin entry and the signed-out pages, plus a button contrast fix. Change the heading if the number differs.

Previous release with notes: v0.0.696.

## Summary

People and the System page are now drawn natively with the next kit and keep every view and action of the old screens. The old config and reference-data routes redirect to their new homes. The signed-out pages (sign-in, forgot password, licence error) use the next tokens and the kit button. A primary button inside the v2 shell had its label drawn in body ink on the accent blue (3.5:1); the label now keeps the accent ink and passes WCAG AA contrast in light and dark.

## Features

- People: native next-kit screen with full parity of the old one (users, roles, invitations), plus redirects from the old config and reference-data routes.
- System page: every view and action of the old page, drawn with the next kit.
- Signed-out pages: sign-in, forgot password and licence error drawn with the next tokens and the kit button.

## Fixes

- Kit primary and danger buttons keep their own ink colour when the screen sits inside the v2 root. The v2 shell's `button { color: inherit }` rule had a higher specificity and turned the label dark on blue.
