# v0.0.657

Previous release with notes: v0.0.654.

## Summary

This release brings the journey branches together in the unified interface. It adds the export centre, source and target system comparison, a target template library, load simulation, contact verification, semantic column types, chat alerts, the Aletheia Foresight and Reason screens, and 269 new field-sweep rules across business partner, customer master, material master and Employee Central. The SAP connection is fully editable from Administration, including SAProuter and SNC fields.

v0.0.655 and v0.0.656 shipped without their own notes; their changes are part of the integration described here.

## Features

- Export centre, and on-screen export for every table.
- Source and target system comparison, with field lineage and a survivorship preview.
- Target template library for every migration object, and a DDIC-derived migration load plan.
- Load simulation per migration run.
- Wave gate evidence with a readiness forecast; post-load differences split into expected and real.
- Email, phone and address verification for partners, customers and employees.
- Semantic column types and a trust score for uploads and external databases.
- Slack and Teams chat alerts for score drops, breaches, failed runs, SLA breaches and firewall rejections.
- Tenant quality thresholds and a data collection form.
- New values are checked against the SAP dictionary at the entry gate and in the cleansing queue; learned rules get a DDIC review.
- Approval ETA forecast and statistical explanation of learned-monitor breaks.
- Aletheia Foresight screen (composite projection, go-live date, engine surprises), Aletheia Reason screen and the capability map.
- Change request process analytics; write-back and change requests sign on as the system's own user.
- The SAP connection is editable in Administration, including SAProuter and SNC, with connection test and system removal behind a typed-name confirmation.
- Rules: 102 business partner (BP300 to BP401), 76 customer master (SDCM863 to SDCM938), 37 material master (MM1115 to MM1151) and 54 Employee Central (EC728 to EC781) field-sweep rules.
- The Employee Central blank template uses the SuccessFactors import layout.
- Issues, record and object screens show scoped issue lists, linked rules and records, and SAP codes with their text.
- Cleaning workbooks carry clearer instructions per sheet and column, and flag required fields that are empty.

## Fixes

- Role gating on three screens now matches the backend; the role matrix is documented.
- First-run setup is safe to step back through and covers its empty and error states.
- Start a run links to extraction, so a new user never reaches a dead end.
- Open admin endpoints are gated.
- Numeric casts, sensitive fix templates and the EC773 proof in field-sweep rules are corrected.

## Docs and training

- The competitive gap review marks the new features as built.
- Rule counts and docs are refreshed for the new rule packs.

## Database migrations

- 150 target templates, 151 SAProuter and SNC, 152 system pairs, 153 export CSV format, 154 quality thresholds, 160 semantic type overrides. The alembic head moves from 149 to 160.

## Configuration changes

- Optional: set MERIDIAN_SLACK_WEBHOOK_URL or MERIDIAN_TEAMS_WEBHOOK_URL in the deployment environment to turn on chat alerts. Without them no chat alert is sent.

## Deployment

1. Run the standard update in [docs/meridian-update-guide.md](../meridian-update-guide.md) while no extraction or analysis is running. The update applies the migrations.

## Verification

- `alembic current` reports 160.
- Administration, SAP systems opens the connection form with the SAProuter and SNC fields.
