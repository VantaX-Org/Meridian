# v0.0.695

Status: not yet tagged. This note covers the spec gaps on Home, the Objects list and Monitor, plus help for the next cleaning cycle. Change the heading if the number differs.

Previous release with notes: v0.0.692.

## Summary

Home could act on one object at a time only, and a new tenant saw a bare "Nothing to show yet." This release lets you tick cards on Home and act on them together, explains the first steps when nothing has been pulled yet, adds a pull link to every empty system on the Objects list, and draws a per-day strip of new, resolved and regressed findings on Monitor. The object guide now walks through the next cycle: download the workbook, clean it in Excel, upload it and score again.

## Features

- Home bulk actions: every story card has a checkbox. Ticked cards open a floating bulk bar at the bottom of the feed with the same actions as the Portfolio bulk bar (pull, download, upload, score again, compare). Clear selection empties it. A download of several workbooks shows one toast that counts them.
- First run: when every object on Home still waits for its first pull, a line above the feed says to pull the first object to see its score.
- No system yet: the empty Home now says "Connect a system to start", explains what Meridian does in one sentence, and offers "Use the demo data" beside "Connect a system".
- Objects list: a connected system with nothing pulled yet shows a "Pull from" button that opens that system.
- Monitor: a stacked bar strip above the watched objects shows, per day, how many findings were new, resolved and regressed. It is drawn from the same feed as the run list and shows nothing when the feed is empty.

## Docs

- The object chapter of the user guide has a new section, "The next cycle: download, clean, upload, score again", covering bulk download from Home, the rules for editing the workbook in Excel, the upload panel, scoring the new run and reading the Monitor strip.

## Known gaps

- Several workbooks download one by one, not as a single ZIP; that needs a backend endpoint.
- The bulk bar has no "Add to load" action yet, the download toast has no "Open Upload" link, and Monitor run entries do not show their DQS and delta.
- The per-day strip counts resolved findings only for runs that also have new or regressed findings, because it is built from the findings feed.
