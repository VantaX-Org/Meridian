# v0.0.640

## Fixed

- Seventeen Employee Central rules built date strings with `.dt.strftime`, which raises on columns that hold only empty dates or mixed types. They now build the same strings from the year, month and day parts. A test fails any rule pack that uses `.dt.strftime`.
- Every database migration now has a working downgrade. The downgrades of 088 and 094 keep their data and say why. The 040 downgrade keeps the `meridian_app` role when another database on the same server still grants to it. The 030 downgrade refuses while any system has no host, client or system number, because 029 cannot hold cloud connections.
- Two rules in the demo fixture library (GL018 and AR013) now match the rule library, so the fixture contract test passes.

## Added

- Fifteen Employee Central rules, EC694 to EC708, for fields that had no check. They cover missing department and company names, positions and departments that are their own parent, termination before hire, leave return before leave start, end dates before start dates on certificates, salary, benefits and stock, shift employees with no shift code, a repeated third nationality, negative pensionable salary and benefits rate, and expired work permits on active employees.
- Six material master rules, MM1109 to MM1114, and three customer master rules, SDCM860 to SDCM862, from a field-by-field sweep of MARA, MARC, MARD, MBEW and KNB1. They check reference-material and generic-material links, the stacking factor, the season year, consignment stock without a consignment flag, negative moving-average value on positive stock, the next payee and buying-group links, and a negative bill-of-exchange limit.
- About 135 API routes that the frontend calls now declare a response model. A ratchet test fails if the count of untyped frontend-called routes rises above 202 (it was 337).
- Admin, Users shows each role's description beside its name. The user import preview shows each role code with its name.
- A migration round-trip test runs upgrade, full downgrade and upgrade again in a throwaway database and compares the schema. It runs when `MERIDIAN_TEST_DB_URL` is set.

## Security

- `npm audit` reports no findings in the frontend, the portal, the install worker and the LLM proxy. Two transitive packages without an in-range fix are pinned by overrides.
- The container image removes the optional nginx dynamic modules, which brought in libxslt with two high findings. Meridian loads none of them.

## Notes

- Meridian now ships 9,468 rules: 6,706 hand-authored and 2,762 derived. Every benchmarked rule stays at 1.0 precision and recall.
