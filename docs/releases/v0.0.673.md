Change the heading if the number differs.

Previous release with notes: v0.0.672.

## Summary

Five follow-ups from review. Two of them make the backend safer, two tidy the frontend without changing what people see, and one finishes the move of migration pages under Load.

## Features

- Load in the menu: the Migration destination is now called Load and opens `/load`. Its list holds Prepare, Analysis, Waves, System comparison, Load plan, S/4HANA readiness, Go-live and History. The key is `l`, and `g` then `i` still works.
- Approvals in Fix: the Fix list now links to Approvals, after Requests.
- Redirects: `/system-compare`, `/migration/load-plan`, `/s4` and `/go-live` now send people to the matching Load tab. Before this, `/migration/load-plan` was caught by the wave redirect and never reached the load plan.
- Help for `/load` opens the migration help page.

## Fixes

- Upload check: a check-only upload now reports the same "formulas failed" result as the real upload when a value starts with `=`, `+`, `-` or `@`. Before this, the check could pass a file that the real upload then refused.
- Writeback send: an approval with no stored change hash is now refused with a clear message asking for the batch to be sent back and approved again. It is never treated as approved and never causes a server error.
- The unused upload gate module and the unused chart parts were removed. The two chart sets now live in one kit under `design/next/kit/viz`; the screens look the same in light and dark.

## Docs and training

- The menu, overview and redirects guides describe Load, the new key and the new redirects.
