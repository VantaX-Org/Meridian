# v0.0.670

Previous release with notes: v0.0.662.

## Summary

This release adds the Portfolio home, the Objects list and the shared upload panel to the app-like Meridian redesign. It stays opt-in: the screens sit under /portfolio and /next/objects and are reached only when a person turns on "Try the new Meridian" in Preferences.

## Features

- Portfolio home with five headline figures: average DQS against each object's previous run, objects ready to load, new issues, regressed issues and objects run this week.
- Every object at its newest run as a card: system, owner, the six-step cycle (pull, clean, upload, score, compare, load), days on the current step, DQS with its change and trend line, new, resolved and regressed counts, and the next action as one button.
- The same objects as a sortable table, and a side-by-side comparison of two or more selected objects, exportable to a workbook.
- Search, and filters by system, owner, cycle stage and ready to load, with six sort orders. Server paging at 50 objects a page, so 100 objects and 500 runs load without delay.
- Bulk actions on a selection: pull now (after a confirm that names the count), download the cleaned workbooks and upload cleaned workbooks.
- Upload panel for several workbooks at once. Each workbook is matched to its parent run from the marker Meridian writes into it; a workbook without one asks for its run. Three uploads run at a time, each with its own progress and result.
- Objects list grouped by system, with each code shown beside its text.
- The portfolio rows carry owner, score trend and change, run number, new, regressed and resolved counts and monitor freshness. The fields are optional and the endpoint contract is unchanged; system and owner filters and the new sort keys are added.
- English, German and Japanese copy for all new text.

## Fixes

- Accent chips and quiet buttons on a tinted background now use ink text, which meets the 4.5:1 contrast minimum.
- Stat cards and DQS figures no longer put an aria-label on a plain span; the screen reader text is a hidden span instead.

## Checks

- Unit tests cover paging, the bulk pull of five objects, grouping by system, the upload of five workbooks each linked to its parent run, the run picker for an unmarked workbook and the upload pool limit.
- A browser test runs both screens at 1440 and 390 pixels in light and dark, with no sideways scroll and no serious accessibility findings.
