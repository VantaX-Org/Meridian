# v0.0.653

Previous release with notes: v0.0.652.

## Summary

The target workbook check now closes its own gaps. When an uploaded migration workbook has columns that the last extraction did not read, Meridian learns those columns, adds any SAP table or SuccessFactors entity they need, extracts them on the next run, checks the workbook again on that run and exports it with the columns filled.

## Features

- The workbook check learns every column it can resolve against the system's schema, including SuccessFactors navigation properties. Extraction reads the learned fields on every later run.
- When a learned column sits on an SAP table that Meridian does not carry, Meridian reads that table's fields from the connected system's data dictionary and adds the table to the extraction. When a SuccessFactors sheet names an entity with no table, Meridian creates one.
- "Update the run" starts an extraction with analysis. When the run finishes, the workbook panel selects it and checks the workbook again without another step.
- The SuccessFactors employee data templates fill more of their columns.

## Fixes

- The fleet vehicle type rule checks against table T370FLT instead of a fixed list.
- The README module table shows the correct SuccessFactors rule count.
- Local nginx tuning files survive updates.
