# Meridian accessibility audit, October 2026

Scope: the web interface (the map, canvas and inspector at `/`), the status page (`/status`) and the tenant branding on the sign-in
page, in English, German and Japanese, light and dark theme. Target: WCAG 2.1 level AA. The conformance report built
from this audit is [VPAT-2.5-meridian-2.md](./VPAT-2.5-meridian-2.md).

## Method

| Check | How | Where |
|---|---|---|
| Automated rules | axe-core 4.11 through `@axe-core/playwright`, tags `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`; a critical or serious violation fails the test | `frontend/e2e/v2-a11y.spec.ts` (30 page states x 3 languages x 2 themes at 1440 x 900), `frontend/e2e/v2-status.spec.ts` (status page and enterprise admin at 1440 and 390, both themes), plus the earlier `e2e/v2-*.spec.ts` |
| Keyboard | Playwright drives Tab, Enter, Space, the arrow keys, Esc and Ctrl+Z only; each step checks focus and a visible focus ring | `v2-a11y.spec.ts`, "keyboard only" |
| Zoom and reflow | 200 % zoom of a 1440 window as a 720 CSS px viewport at device scale 2; reflow at 320 CSS px; no sideways scroll and no control outside the viewport | `v2-a11y.spec.ts`, "200% zoom at 1440" and "reflow at 320" |
| Languages | German and Japanese at 1440 and 390: the 280 px map keeps its width and no map row overflows, the top bar keeps every control on screen, the inspector does not scroll sideways | `v2-a11y.spec.ts`, "layout"; screenshots `frontend/e2e/__screenshots__/v2/i18n-{de,ja}-*.png` |
| Motion | `prefers-reduced-motion: reduce` emulated; the computed `animation-name` of a change notice and of the run timeline's marks must be `none` | `v2-a11y.spec.ts`, "prefers-reduced-motion" |
| Contrast arithmetic | WCAG relative luminance for tokens and tenant accents | `lib/v2/theme.ts`, `design/v2/__tests__/Enterprise.test.tsx` |
| Names, roles, states | Testing Library queries by role and accessible name | `design/v2/__tests__/*.test.tsx` |

Environment: Chromium (Playwright 1.59, browser build 1194), the production build (`npm run build`, standalone server),
fixture mode (`?fixture=1`) so every page renders the same demo tenant with no backend.

Not done: a screen reader session (NVDA, JAWS, VoiceOver), testing with users with disabilities, a text-spacing
override test (1.4.12), and a review of the training recordings (1.2.x). These are marked Not Evaluated in the report.

## Pages checked by axe

Landscape; landscape with the rule inspector; landscape as Basis with the system inspector; waves; object; object
Rules tab; rule; Work (steward); Work approvals (owner); Runs; Runs jobs; People; Reports; System; Inbox; Preferences;
Help; Administration; Admin Users; Admin Settings (with Appearance and Compliance); Admin Jobs and system update (with
the diagnostics bundle); Admin Audit; Admin Runs and jobs; Status. The status spec adds the status page, Appearance and
SCIM provisioning at 390 and 1440 in both themes.

## Results

- **axe**: 192 runs (180 in `v2-a11y.spec.ts`, 12 in `v2-status.spec.ts`), between 26 and 34 rules passing per page,
  **0 critical, 0 serious, 0 moderate and 0 minor violations** after the fixes below.
- **Keyboard**: all five flows pass with the keyboard alone: landscape to object to the rule inspector; a ledger
  decision then Undo with Ctrl+Z; approving a batch then Undo; starting an extraction as Basis (pick an object with
  Space, start it with Enter); an administrator inviting a user. Skip links and landmarks are checked in the same spec.
- **200 % zoom**: no sideways scroll and no clipped control on seven pages in all three languages.
- **Reflow at 320**: no sideways page scroll on five pages (German, the longest words).
- **Languages**: the map stays 280 px with no overflowing row, and the top bar and inspector hold, in German and
  Japanese at 1440 and 390.
- **Reduced motion**: the notice's slide (`m2-toast-in`) and the timeline's fade (`m2-tl-in`) are off under
  `prefers-reduced-motion: reduce`; without it the notice slides in.
- Vitest, tsc, ESLint and lint:tokens pass; see the commit for counts.

## Findings and fixes

| # | Finding | WCAG | Severity | Fix |
|---|---|---|---|---|
| 1 | The server diagnostics block (a scrolling `<pre>`) in Help, Contact support could not be reached by keyboard (axe `scrollable-region-focusable`, serious, every language and theme) | 2.1.1 | Serious | `tabIndex={0}` on every scrolling code block in the help panel |
| 2 | The inbox button's name "Inbox, 7 unread" did not contain its visible text "Inbox 7" | 2.5.3 | Moderate (manual) | Name is now "Inbox 7, unread" in every language |
| 3 | Every page had the window title "Meridian" | 2.4.2 | Moderate (manual) | The page title follows the `h1` ("Users – Meridian"); the status page reads "Status – Meridian" |
| 4 | The inspector had no landmark of its own and no skip link | 2.4.1, 1.3.1 | Moderate (manual) | The inspector is a complementary landmark named "Inspector" holding the dialog; skip links to the content, the map and the open inspector |
| 5 | The status strip was not a landmark | 1.3.1 | Minor | It is a `footer` (contentinfo) named "Status" |
| 6 | `<html lang>` stayed `en` in German and Japanese | 3.1.1 | Serious (manual) | The shell sets `lang` on `<html>` and on its root from the interface language |
| 7 | The focus ring was a literal in the stylesheet, and menu items showed focus by background only | 2.4.7 | Minor | Tokens `--m2-focus` and `--m2-focus-w`; menu items add an inset ring |
| 8 | The decision select in the ledger compared its value with a translated word, so German and Japanese rows lost their current decision | 4.1.2 | Serious (found by the keyboard walkthrough) | The select's values stay fixed; only its words are translated |
| 9 | The "Back to the landscape" link inside the note on the Connect a system page was told from its sentence by colour only (axe `link-in-text-block`, serious, every language and theme) | 1.4.1 | Serious | Links inside a note are underlined |

## Known gaps (not fixed in this step)

| Gap | WCAG | Why it stays | Next step |
|---|---|---|---|
| Text field and secondary button borders (`--m2-line-2`) are about 1.6:1 against the sheet | 1.4.11 | A change to the design tokens of every screen; controls are identified by label and position | Propose a 3:1 border token to design |
| Go-to sequences (g then l, w, r, p) and `?` are page-wide and cannot be switched off | 2.1.4 | Needs a preference and the dispatcher to honour it | Add "Keyboard shortcuts on/off" to Preferences |
| The status page refreshes every minute and the job line follows jobs, with no pause | 2.2.2 | Auto-update is the point of both; neither moves or blinks | Add a pause control on the status page |
| A change notice's Undo shows 6 seconds (Ctrl+Z keeps working 10 minutes) | 2.2.1 | Short notices keep the canvas clear | Keep the notice while it has focus or hover |
| The invite email field uses `autocomplete="off"`; profile fields carry no tokens | 1.3.5 | Not part of this step's files | Add `email`, `name` tokens |
| English text from the server inside German and Japanese pages is not marked `lang="en"` | 3.1.2 | The client cannot tell a translated server string from an English one | Have the API send a language with prose fields |
| Help chapters and training recordings are English only and the recordings have no captions | 1.2.2, 3.1.2 | Content, not interface | Caption and translate the recordings |
