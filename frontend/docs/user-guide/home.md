# Home

Home answers one question: how healthy is our SAP data, and what should I do next? Each role lands on its own version, built from the same latest run.

## The verdict

The large sentence at the top says whether your data is ready, with the number that caused that verdict. The button under it is the one next action worth taking. The data quality score sits beside it, with the change since the previous run.

## The cap

A critical failing rule caps the score: one critical rule limits it to 85, two or more to 70. When that happens the page shows a "Capped" pill and names the rules responsible, so you can see exactly what to fix to lift the score. The cap is explained under [the data quality score](/docs?page=objects).

## What else is on the page

- **Dimensions** shows the six quality dimensions as bars. Select one to see the objects behind it.
- **Score over runs** is the trend. Select a point to open that run.
- **Objects, worst first** lists the objects that need attention, with the rule blocking each one.
- **A row of tiles** for your role: leads see objects not ready, stewards their inbox, Basis unhealthy systems.

Every number is a link. Select it to open the records behind it.

## Getting set up

A new installation shows a checklist: connect a system, complete a first run, create a first fix batch, invite your team and set an alert channel. Each item links to its page and ticks itself when done. Dismiss it any time.

## Taking a tour

Open the help menu and choose **Tour this page** for a guided walk.
