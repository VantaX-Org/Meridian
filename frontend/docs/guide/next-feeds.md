# Portfolio, Objects, Work and Monitor

These four screens are the feeds. Each one answers a different question about every object and every run.

## Portfolio

Portfolio lists every object on every connected system at its newest run. Open an object to see its runs and its trend.

## Objects

Objects groups the same list by system. Each row shows the object, its score, its cycle step and its owner.

## Work

Work holds the tasks that need a person: issues, approvals and cleaning jobs. Use the tabs to switch between them.

## Monitor

Monitor shows what changed, run by run, across all objects. Use the segments All, New, Regressed and Resolved to narrow the list.

When an object has more than one run in the feed, a trend line shows its new plus regressed records in each run, oldest to newest. A falling line means the object is getting cleaner. Open this run to see the run itself, or open all in Compare to see the change against its baseline.
