# Meridian brand assets

The meridian M: a square tile in the accent colour with an M whose centre
vertex continues as a plumb line past the baseline. The line is the
meridian; the letterform is the product.

## Files

- `mark-light.svg` / `mark-dark.svg` — the tile mark, for light/dark surfaces
  (rail brand block, favicon, PWA icons, XLSX/PDF covers).
- `mark-mono.svg` — no tile, strokes in `currentColor`. For print, email
  signatures and the PDF cover when printed in black. Used at large size
  (96px) on the sign-in brand panel.
- `wordmark-light.svg` / `wordmark-dark.svg` / `wordmark-mono.svg` — mark +
  "Meridian" set in Public Sans 600, for places that cannot load the web
  font (PDF cover, OpenGraph image, email).
- `brand.json` — the four brand colours as data, for files where a raw hex
  literal would fail `lint:tokens` (`app/manifest` inputs, rasterisation).
- `icon-32.png`, `icon-192.png`, `icon-512.png`, `icon-512-maskable.png` —
  rasterised PNG fallbacks and PWA icons, generated by
  `npm run brand:rasterise`.

## Rules

- Clear space: mark height × 0.25 on all sides, minimum.
- Minimum size: 16px. The plumb line is the one asymmetric detail and it
  must survive at that size.
- Never recolour the mark outside the light/dark/mono colourways above.
- Never place the tile mark on the accent colour — there is no contrast
  between tile and background at that point.
