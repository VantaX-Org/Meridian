# Meridian brand assets

The mark is a gauge and a meridian: a 270 degree measuring arc, open at the
top like an instrument dial, crossed by one vertical line that runs past the
arc at both ends. Two strokes, one weight (3 on a 32 grid), round caps, no
fill, no gradient. The arc is ink; the meridian line is the accent.

## Files

- `mark-light.svg` / `mark-dark.svg` - two-tone mark for light/dark surfaces.
- `mark-mono.svg` - both strokes in `currentColor`, for print and photography.
- `lockup-light.svg` / `lockup-dark.svg` - mark plus "Meridian" in Public Sans
  600 (letter-spacing -0.01em, outlined from the OFL font). The UI wordmark is
  now Manrope 700; these outlined lockups are kept until redrawn. The accent is on
  the meridian line only. In the app the lockup is HTML (mark plus text).
- `apple-icon.svg` - 180x180 design source for `maskable-512.png`. The live
  apple icon is `app/apple-icon.tsx` (ImageResponse): the two-tone mark on a
  plain canvas tile, no cover, no gradient.
- `brand.json` - brand colours as data, for files where a raw hex literal
  would fail `lint:tokens`.
- `icon-*.png`, `maskable-512.png` - PWA icons, generated by
  `npm run brand:rasterise`.
- The favicon is `app/icon.svg` (stroke 3.5, follows the OS colour scheme) with
  `app/icon.png` as fallback. The Open Graph image is `app/opengraph-image.tsx`.

## Rules

- The wordmark is always type-set Manrope 700. Never redraw the letters.
- Clear space: half the mark's height on every side.
- Minimum size: mark 16px; lockup 96px wide. Below 96px use the mark alone.
- Two-tone on canvas/sheet surfaces only; mono on photography or when the
  accent is unavailable.
- Never rotate, shadow, fill or close the arc, change the gap, or put the mark
  on a tile (the OS app icon is the one exception).
